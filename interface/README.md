# interface/

**À coder à l'étape 6.**

`application.py` : menu console en français permettant de tester la
connexion, choisir une entité (client, fournisseur, article, devis,
facture...), choisir une opération CRUD, saisir les données, exécuter et
afficher le résultat ou les erreurs/validations. Point d'entrée appelé par
`main.py`.
